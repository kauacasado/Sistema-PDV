
# Sistema PDV

Sistema de Ponto de Venda (PDV) desenvolvido em Python como projeto acadêmico em grupo.

## Objetivo

Desenvolver um sistema para auxiliar no gerenciamento de produtos, clientes, vendedores, vendas e controle financeiro de um estabelecimento comercial.

## Funcionalidades planejadas

- [x] Cadastro de produtos
- [x] Listagem de produtos
- [ ] Cadastro de clientes
- [ ] Cadastro de vendedores
- [ ] Realização de vendas
- [ ] Controle de estoque
- [ ] Cálculo de comissões
- [ ] Cálculo de impostos
- [ ] Relatórios financeiros

## Tecnologias utilizadas

- Python
